# Contributing

[中文](CONTRIBUTING.md)

Describe a reproducible issue, expected behavior and affected modules. Work on a branch of the public copy, not a running robot. Implementations live under `src/charging_robot`; root entry points preserve launch compatibility.

Include behavioral changes, relevant test commands/results and unverified areas. Select regressions by impact; run the full local suite for import/path changes. Passing tests is not field safety certification.

Submit only material you may publish. Preserve third-party notices and identify their licenses separately. Your own contributions are provided under this project's MIT terms; copyright transfer is not required.

Exclude maps, trajectories, logs, calibration, credentials, device addresses, site authorization and thesis text. Keep public configuration disabled. Prefer synthetic reproductions; review rights and sensitive content before sharing real data.
