# 本车原版源码恢复与使用说明

本包于 2026-11-09 在 pvpproof 准备，用户已明确授权将原版源码、模板、标定和现场配置公开。它包含项目工作台与从机器人读取的机械臂原件，目标为原车 `/home/nvidia` 布局。没有用昨天重建的 workflow/runtime 替代现场原版。

## 先看哪个目录

- `robot_originals/`：同车恢复来源。599 个原文件有逐文件 SHA-256，包含原版 charge_robot、ICP/V3、模板、标定、配置、仿真与 DOBOT 依赖。
- `arm_stack/`：去敏的阅读/开发视图，存在路径占位和现场相机 TF 省略；不要用它覆盖车上运行目录。
- `src/charging_robot/`：工作台源码；`start.sh --offline` 是不连接设备的界面预览。非 offline 入口可能启动设备。
- `robot_originals/ENVIRONMENT.md`：ROS、RealSense 与 Python 环境说明，以及已确认和待确认的版本。

## 包内已有资料

包括充电口模板 `socket_frame_and_rim_2mm_m.ply`、手眼标定 `hand_eye_calibration_result_ros_24mm.npz`、相机测试参数、保存的机械臂初始关节姿态、枪头补偿、实际算法配置、原版执行适配器、Nova2 模型/网格、MoveIt 配置和 126 个 ROS 接口定义。模板与现场读取文件的 SHA-256 一致。

这些标定、补偿和位姿只针对本车。控制器地址和原始绝对路径也保留在原件中。不要将它们当作其他机器人通用参数。

## 解压和核对

GitHub 仓库 ZIP 解压后，进入名为 `autonomous-charging-robot-<提交号或分支名>` 的目录；根目录应直接包含 `start.sh`、`README.md` 和 `robot_originals/`，没有额外的 `project/` 层。也可使用 `git clone`；使用入口与完整操作顺序见 [How to use](HOW_TO_USE.md)。

原件哈希检查可在仓库根目录运行（系统 Python 与 NumPy，不启动设备）：

```bash
/usr/bin/python3 tests/test_robot_original_bundle.py
```

若拿到的是另行提供的本地完整系统 tar.gz 包，其顶层目录为 `autonomous-charging-robot-full-system-20261109`，项目位于 `project/`，该格式才使用以下命令：

```bash
tar -xzf autonomous-charging-robot-full-system-20261109.tar.gz
cd autonomous-charging-robot-full-system-20261109
sha256sum -c SHA256SUMS
cd project
```

先校验文件，不会启动 ROS、相机或机械臂。

## 恢复原文件

车和机械臂停稳、相关服务关闭后，先预览：

```bash
/usr/bin/python3 robot_originals/deploy_originals.py
```

确认目标是这台车的 `/home/nvidia`，确实需要恢复时执行：

```bash
/usr/bin/python3 robot_originals/deploy_originals.py --apply
```

工具校验来源文件后复制，并将被覆盖的旧文件备份到 `/home/nvidia/.charging-source-backups/`。它不安装依赖、不构建工作空间、不启动服务、不执行动作。遇到符号链接目标会拒绝并要求人工核对，不会跟随链接覆盖其他目录。

已核实原车 `/home/nvidia/bin/charge_robot` 链接到 `/home/nvidia/nova2_tools/charge_robot.sh`。恢复工具不改该链接；保留原链接即可。

## 环境和构建

同车原有 ROS Humble、RealSense 驱动、`charging_robot_env` 和已经构建的工作空间可继续使用；本包不复制 OS、虚拟环境二进制或 install/build 缓存。

若要重建，以下是源码对应的命令，**本次尚未执行构建验证**：

```bash
source /opt/ros/humble/setup.bash
cd /home/nvidia/nova2_ros2_ws
rosdep install --from-paths src --ignore-src -r -y --rosdistro humble
colcon build --symlink-install
source install/local_setup.bash
```

原仿真 package.xml 声明的 `moveit_commander` 是否能在现用 rosdep 环境解析仍需确认，不能据此宣称上面命令已经通过。Python/Jetson 架构和 RealSense 绑定说明见 `robot_originals/ENVIRONMENT.md`；环境记录不是跨平台的一键 pip 锁文件。

## test 和 home 做什么

以下是运行入口说明，不是本次已经执行的命令：

```bash
charge_robot test
charge_robot home
```

`test`：启动真实连接、视觉与规划环境，按 ICP 相机预对齐 → V3 测量 → 枪头预备位 → 75 mm 轴向插入的顺序推进。每段运动仍需终端人工确认，失败不继续下一阶段；不会自动 home 或底盘返程。

`home`：独立回机械臂保存的初始姿态。若有成功插入且未撤回记录，先撤回再回位；异常或不确定状态按原版提示处理。机械臂回位不是底盘回导航起点。

运行入口可能真实驱动机械臂。应在环境、模型/反馈和现场条件核验后，再按原版逐段确认，不要用 test/home 当成普通安装检查。
