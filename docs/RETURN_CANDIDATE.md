# 实测轨迹返程候选

本候选已完成隔离实现与测试，未部署至机器人运行目录，未驱动实车，未完成实车验收。它始终依赖人工持续监护，不具备后向自动避障能力。

## 工作流

1. 去程保存同一测量时刻的地图位姿、里程计位姿和地图到里程计变换，并绑定地图指纹、栅格内容及定位会话。
2. 返程倒序使用实测几何，保留车身朝向；跟踪器使用当前实测位姿反馈计算转向，不回放去程速度，也不通过重新规划冒充原路返回。
3. 准备返程前检查地图、坐标链、新鲜度、停稳状态和现场确认。缺少新证据的旧记录不会自动升级为可执行路线；不平移或旋转轨迹来掩盖定位差异。
4. 独立仲裁器负责软件控制权交接。厂家驱动订阅与导航输出须成套重映射；只替换界面不能形成独占输出。
5. 运行时必须持续按住。松手、失焦、GUI 或仲裁心跳失效、定位或里程计异常、控制源竞争、导航重新占权、超时及距离边界均请求零速度并锁存，不自动恢复。
6. 到达记录起点后继续请求零速度，以新鲜反馈确认连续停稳，再保存实际停点。短测、故障或部分返程不覆盖起点。

候选限制倒车速度为 0.05 m/s、最小转弯半径为 1.78 m。默认短测在 3 秒或实测 0.15 m 先到时请求停止。这些是软件请求门限，未经实车标定，不是物理停止距离或精度保证。

## 默认禁用与现场边界

`config/return_commissioning.json` 默认为 false，实车仲裁对所有模式输出零。不能用修改配置代替现场验收。独立软件仲裁无法保证自身进程、ROS 通信、主机或电源故障后车辆仍会物理停住；下位机失联停车行为是实车放行前仍需验证的项目。

现场阶段至少需要确认车辆停稳、机械臂与枪头收拢、线缆和通道清空、物理急停可及、外部控制源交接、实际 ROS 图和订阅重映射，以及新轨迹的坐标一致性。随后在现场监护下验证短直线、松手停车和缓弧转向，才能评估完整返程。仓库不执行这些动作，也不提供自动部署脚本。

## 发布副本的改动

发布副本没有改动原候选或机器人运行工程。设备用户路径改为环境变量或当前用户路径；厂家导航参数被排除，启动导航须显式提供本地配置；示例占位文件被拒绝。纯数值工具删除了历史设备覆盖审计和自动写结果文件的入口。ROS 集成测试的隔离检查改用显式异常，避免 Python 优化模式移除 assert 后失去检查。
