# 当前发布版本验证

本提交公开单击返程、GUI运行租约、驱动v2状态/复位交接及启动解锁确认修复。维护者报告现场单击返程已正常完成；自动化核查只读查看运行记录及源码哈希，没有代替用户操作车辆。返程期间无仲裁故障，结束记录为complete、零速停车，随后服务正常退出。

启动阶段仍记录过一次驱动状态与原始反馈过期后的重锁。两次显式解除均收到确认，不能将后一次新故障误说成旧ACK竞态，也不能宣称所有启动期反馈抖动已经解决。这里仅公开结论，不附现场日志、地图、轨迹或授权标识。

## 尚未证实的范围

- 整个驱动进程或主机失效时，MCU独立命令超时和实际停车行为仍未验证；厂家serial读写超时、正常退出零帧不能证明崩溃停车。
- PTY和源码审查不证明真实USB串口双句柄/控制线兼容、MCU收到并执行帧或地面停车距离。
- 原始速度积分不等于独立地面位置，无法保证识别轮滑或被推动；没有后向自动避障，轨迹不能发现新障碍。
- 公开配置仍为disabled、commissioned=false，现场条件false，无单次授权。维护者设备上的成功不构成其他硬件、无人运行、机械臂插接或电气充电验收。

当前0.15m/s目标、0.4m/s反馈边界、4m路线与90s许可上限是调试策略设定，并非已标定地面速度或通用制动能力。
